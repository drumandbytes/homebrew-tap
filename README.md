# homebrew-tap

Homebrew tap for drumandbytes tools and casks.

## Installation

```bash
brew tap drumandbytes/tap
```

## Available Casks

### eraser
Send data removal requests to data brokers ([eraser.drumandbytes.dev](https://eraser.drumandbytes.dev))

```bash
brew install --cask drumandbytes/tap/eraser
```

### music-router
Stops Music.app auto-launch and routes media keys elsewhere. Requires Apple Silicon and macOS Ventura or later.

```bash
brew install --cask drumandbytes/tap/music-router
```

### omniroute
Unified AI gateway and model router ([omniroute.online](https://omniroute.online))

```bash
brew install --cask drumandbytes/tap/omniroute
```
